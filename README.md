# Employee Knowledge Portal

Build a knowledge management system for small organization where all the emplotyees can manage everything related to it, like they can do courses or read policies and all the knowledge of that employee stays in that portal.

Built and shipped end-to-end by the [SDLC AI Pipeline](https://sdlc-ai-pipeline.vercel.app) — requirements, stories, architecture, implementation, AI code review, tests, CI, and deployment.
